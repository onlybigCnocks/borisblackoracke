## Что добавим

Новый широкий баннер-секцию на главной странице между блоком сканера («Проверь проект») и блоком «АРХИТЕКТУРА / 19 перекрёстных слоёв анализа». Стиль — в нашей фирменной тёмной/красной палитре (карточка с тонкой красной рамкой/свечением, как остальные секции).

### Содержимое баннера

- Крупный заголовок: **«Для доступа к полному функционалу — напишите нам»** (RU) / **"For full access — get in touch"** (EN)
- Короткий подзаголовок (1 строка)
- Кнопка **«Связаться»** / **"Contact us"** — по клику открывается модальное окно с формой

### Форма (модалка)

Поля:
1. **Организация** (text, required, 1–150 символов)
2. **Ваш email** (email, required, валидный формат)
3. **Сообщение** (textarea, required, 10–2000 символов)

Кнопка **«Отправить»**. После успеха — toast «Сообщение отправлено, мы свяжемся с вами в ближайшее время». Без указания, куда именно ушло письмо.

### Скрытие получателя (главное требование)

Адрес `andrey_prosto@bk.ru` НЕ должен фигурировать ни в каком клиентском коде (ни в .tsx, ни в .env с префиксом `VITE_`, ни в network-запросах из браузера). Иначе пользователь сможет открыть DevTools и увидеть его.

Решение — отправка через серверную Edge Function:

1. Включаем **Lovable Cloud** (бесплатно, без отдельного аккаунта Supabase).
2. Настраиваем встроенную **email-инфраструктуру Lovable** (свой sender-домен — потребуется один шаг от вас в диалоге настройки домена).
3. Создаём Edge Function `send-contact-message`, которая:
   - принимает только `{ organization, email, message }`,
   - валидирует входные данные (zod),
   - имеет простой rate-limit по IP (не больше N запросов в минуту), чтобы форму не использовали как спам-релей,
   - вызывает встроенный механизм отправки писем Lovable с захардкоженным внутри функции получателем `andrey_prosto@bk.ru` (этот адрес живёт ТОЛЬКО на сервере, в браузер не попадает),
   - возвращает клиенту просто `{ ok: true }`.
4. На клиенте вызываем функцию через `supabase.functions.invoke('send-contact-message', ...)` — в network-запросе виден только URL функции, без получателя.

### Шаблон письма

React Email шаблон `contact-message.tsx`:
- Subject: `Новое сообщение с сайта BORIS — {organization}`
- Тело: Организация / Email отправителя / Сообщение (с авто-экранированием React).
